в рабочей библиотеке; 10 фотографий сохранены дополнительно.
Подробности — [отчёт о публикации](PRODUCTION_20261104.md), действующие URL —
[published-20261104.json](published-20261104.json). Таблица ниже сохраняет исходный
результат подбора и пометки о различиях вариантов.

В архиве локальные кандидаты для просмотра. «Совпадает движение» не означает проверенную лицензию для публичного приложения.
Для новых материалов FitnessProgramer разрешение на повторную публикацию не подтверждено; источник сохранён у каждого файла.
Для уже используемых материалов из старого проекта права отдельно не проверялись.
Анимации с отличиями скамьи, хвата, опоры или тренажёра отмечены отдельно. Спорные названия не утверждались автоматически.
