# Сигнал окончания запланированного отдыха

3 ноября 2026. Изменение `WorkoutClockPanel` по запросу пользователя.

- До окончания установленного отдыха показывается обычный обратный отсчёт.
- На границе времени появляется жёлтая подпись «Отдых окончен», цифры становятся
  жёлтыми и показывают превышение: `+00:00`, `+00:01` и далее. Статус сохраняется
  до начала следующего подхода; цвет дополнен текстом и доступным объявлением.
- Кнопка «Начать подход» два раза мягко меняет оттенок синего за 1,8 секунды.
  Постоянного мигания нет. При `prefers-reduced-motion: reduce` анимация отключена,
  подпись и цвет таймера остаются. Существующий виброотклик сохранён.
- Начало подхода убирает сигнал; отмена замера возвращает исходный отдых.
  Дедлайн и превышение сохраняются после перезагрузки и при открытии главной.
- Отдых без заданной длительности, отдых между упражнениями и счётчик
  завершённых подходов не вызывают этот сигнал.
- Высота панели остаётся 81 CSS px без системного safe area, положение кнопки
  при смене состояния не меняется. Цвет цифр: amber-300, вместо цвета ошибки.
