# Компактный интерфейс тренировки

29.10.2026. Перенос согласованного интерактивного макета в React-приложение.

## Изменения

- Закреплённая панель занимает 81 CSS-пиксель без нижней навигации и системного
  safe area: таймер слева, основное действие справа. Начало, завершение подхода
  и переход к следующему упражнению сохраняют положение кнопки. Отмена замера
  и пояснения доступны по нажатию таймера.
- Поля веса, повторов и отдыха высотой 36 px, с окружающими зонами нажатия
  не меньше 44 px и шрифтом 16 px. Суммарный вес показан отдельно под вводом.
- Подсказка активного подхода занимает одну строку, например
  «Гриф 20 · на сторону: [15]». Нажатие раскрывает полный расчёт. Используются
  существующие формулы, снимок правил подхода и выбранный пользователем набор
  блинов; прежние единицы истории сохранены.
- Тип подхода, RIR, RPE, удаление и отдельный старт в суперсете доступны через
  меню строки. На главной редкие действия с упражнением перенесены в его меню.
- Место тренировки выбирается заметными кнопками «Зал / Дома / Другое».
  Главная показывает план и прогресс, без повторных ссылок истории и аналитики.
- Библиотека доступна в нижней навигации. Поиск, группы, техника, создание,
  редактирование, выбор и замена упражнений используют существующий каталог.
  Очередь остаётся доступной пятой кнопкой при наличии неотправленных изменений.
- Настройки открываются на весь экран, с отдельной кнопкой сохранения внизу.
  Сохранены экспорт, импорт, вес тела, блины, разминка, пресс, заминка и выход
  из HealthOS. Экспорт и импорт находятся в начале экрана.

## Проверки

- `npm test`: 162/162; production-сборка TypeScript/Vite — успешно.
- `workoutDock.browser.cjs`: desktop 1280×900, mobile 390×844, compact 320×720;
  кардио, силовые, неподвижная кнопка, компактная высота, отмена, ручная длительность,
  перезагрузка без сети, очередь и последующая синхронизация.
- `workoutFlow.browser.cjs`: повторение старой тренировки, замена после частичного
  выполнения, измерение времени, офлайн-восстановление без дублей, старые единицы.
  Проверены пары введённого и общего веса: 2→4, 60→60, 30→70 кг.
- `exerciseCatalogue.browser.cjs`: поиск, группы, добавление, замена, очистка,
  офлайн-перезагрузка и сохранение очереди на трёх размерах экрана.
- `compactWorkoutUx.browser.cjs`: полный состав настроек, скачивание экспорта,
  обработка существующего отказа импорта, сохранение веса тела и блинов, библиотека,
  компактная подсказка с пересчётом набора блинов, раскрытие деталей, RIR/RPE/тип,
  место тренировки, продолжение замера после настроек и пять пунктов навигации.
- `localHistory.browser.cjs`: desktop/tablet/mobile/compact; история и аналитика
  из локального журнала, общие периоды, сохранение данных при сбое обновления,
  офлайн-повторение и неизменная очередь после перезагрузки. Дата этого теста
  закреплена на 21 октября, чтобы относительные периоды соответствовали фикстуре.
- Снимки рабочего React UI проверены на desktop/mobile/compact. Новые компоненты
  и CSS прошли механическую проверку Impeccable без замечаний.

Браузерные записи выполнялись исключительно через loopback MemoryClient с настоящим
Python-адаптером. Внешние API подменялись. Рабочие тренировки, схема БД, серверный
код и секреты этим обновлением не изменены. Физический iPhone/Safari не проверялся.

## Известное ограничение импорта

Существующий `SupabaseStore.import_data` возвращает отказ: прямой импорт бэкапа
отключён в пользу проверенного импортёра HealthOS. Интерфейс сохраняет кнопку
и обработку отказа. Этот релиз не включает реализацию нового серверного импортёра
и не обещает успешный импорт через данный API. Экспорт проверен скачиванием JSON.

Артефакты проверок хранятся вне публичного Git:
`D:\Projects\GymApp-backups\workout-dock-20261029\implementation-*`.
