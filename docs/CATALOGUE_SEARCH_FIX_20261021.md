# Поиск упражнений и группы мышц

21.10.2026. Исправление регрессии фронтенда. Backend, прокси и база не менялись.

## Причина и изменение

После переноса навигации поле поиска отображалось только при непустом запросе:
начать ввод с пустого экрана было невозможно. Состояние выбранной группы мышц
оставалось в приложении, но соответствующие кнопки не передавались в справочник.

- Поле «Название упражнения» всегда видно в справочнике, при добавлении
  и замене упражнения в тренировке. Заголовок экрана сохраняется при вводе.
- Восстановлены «Все» и группы мышц. В общем списке упражнения сгруппированы
  под заголовками мышц; внутри группы сохраняется алфавитный порядок.
- Поиск по названию и группа работают совместно и локально, без задержки
  на сетевой запрос или debounce. Регистр и пробелы по краям не мешают поиску.
- Есть очистка запроса и восстановление полного списка при пустой выдаче.
  Очистка только строки сохраняет выбранную группу; общий сброс очищает оба поля.
- Поиск не перехватывает фокус при каждом изменении. Поля и кнопки доступны
  с клавиатуры, на экранах 320 px и с сенсорным вводом.
